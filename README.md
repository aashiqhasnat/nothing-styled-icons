## ✨ Key Features

- 🎨 **Official App Launcher Icon:** Signature launcher icon with Android 13+ Nothing OS monochrome themed icon support.
- 🖼️ **Over 4,000+ Handcrafted Dot-Matrix Glyphs:** High-definition vector icons celebrating the industrial dot-matrix design language with crisp contrast and adaptive shapes.
- 🌓 **Dual-Theme Perfection (Light & Dark Mode):**
  - **Light Mode:** Pure clean white circular plates with high-contrast black line-art glyphs and red focal accents.
  - **Dark Mode:** Deep matte charcoal plates with glowing white line-art glyphs and vivid red focal accents.
- 🚀 **1-Tap Launcher Integration:**
  - Auto-detection for installed custom launchers (Nova, Niagara, Lawnchair, Smart, Action, and more).
  - One-tap deep-links directly into each launcher's icon settings without mutating launcher state.
- 📥 **Local-Only Icon Request Manager:**
  - In-app request queue backed by local Room database.
  - Submit icon requests directly from your installed app list—100% offline, no cloud backend required.
- 🔍 **Instant Search & Category Catalogue:** Real-time filtering with live result counter and quick category navigation.
- 🔒 **Rock-Solid Privacy & Zero Trackers:**
  - Fully offline operation with no network permissions requested (`android.permission.INTERNET` omitted).
  - Zero analytics, zero ad trackers, zero telemetry, and no DRM/anti-piracy bloat.
